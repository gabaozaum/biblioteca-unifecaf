# Biblioteca Digital UniFECAF

Primeira interface web da Biblioteca Digital UniFECAF, feita somente com HTML e CSS.

## Estrutura
```
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
└── assets/
    └── imagens/
```

## Como abrir
Dê dois cliques em `index.html` ou publique a pasta no GitHub Pages / Netlify.

## Observações
- As imagens são ilustrações em SVG criadas para o projeto; podem ser trocadas por fotos mantendo os mesmos nomes de arquivo.
- E-mail, telefone e horários das unidades são exemplos: substitua pelos dados reais da instituição.
