# Biblioteca Digital UniFECAF

Primeira interface web da Biblioteca Digital UniFECAF, desenvolvida com HTML e CSS para a disciplina de Design Web.

**Site publicado:** https://gabaozaum.github.io/biblioteca-unifecaf/

## Sobre o projeto

O site transforma um protótipo de baixa fidelidade em uma interface moderna, responsiva e acessível, com as seções definidas no protótipo: menu, banner inicial, sobre a biblioteca, livros, unidades e contatos.

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, Grid, Flexbox, media queries)
- Fontes Poppins e Source Sans 3 (Google Fonts)
- Nenhum framework, template pronto ou JavaScript

## Como abrir

Acesse o link do site acima ou baixe o repositório e abra o arquivo `index.html` no navegador.

## Observações

- As imagens são ilustrações em SVG criadas para o projeto.
- Textos, e-mail, telefone, horários e livros são fictícios, criados para fins acadêmicos.
